
# ЭЩКЕРЕ — сайт современного театра

Учебный проект по практической работе №1
«Маршрутизация в Django».

## О проекте

ЭЩКЕРЕ — демонстрационный сайт современного театра
с единым оформлением и системой маршрутизации.

## Реализованные страницы

- Главная
- О театре
- Контакты
- Как нас найти
- Афиша
- Билеты

## Использованные технологии

- Python
- Django
- HTML
- CSS
- Django Template Language

## Особенности

- Маршруты определены в приложении main
- Именованные URL-маршруты
- Наследование шаблонов через base.html
- Единый дизайн всех страниц
- Выпадающее навигационное меню
- Адаптивная вёрстка

## Запуск проекта

1. Создать виртуальное окружение:
   py -m venv .venv

2. Установить зависимости:
   .venv\Scripts\python.exe -m pip install -r requirements.txt

3. Запустить сервер:
   .venv\Scripts\python.exe manage.py runserver

4. Открыть в браузере:
   http://127.0.0.1:8000/
